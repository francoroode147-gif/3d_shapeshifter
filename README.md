# 3D Shapeshifter Website

A standalone responsive website for 3D Shapeshifter.

## Files
- index.html — complete website
- style.css — styling and responsive layout
- script.js — navigation, animations, gallery filters/lightbox and quote form

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload these three files.
3. In GitHub, open Settings → Pages.
4. Select Deploy from branch → main → /root.
5. Save and wait for the site to publish.

The quote form currently opens the visitor's email application. This keeps the site fully static/free. A backend or form service can be connected later if needed.
